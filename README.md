# 📚 StudyNest – Smart Learning Management Platform

**StudyNest** is a full-stack learning management platform designed to connect students and teachers in one place. It helps students access learning materials, complete assignments, participate in quizzes and exams, track their progress, and organize their study schedules. Teachers can manage students, share educational resources, create assessments, and monitor academic performance.

The platform also integrates AI-powered learning assistance and YouTube-based learning recommendations to support a more personalized learning experience.

## ✨ Features

### 👨‍🎓 Student Features
- Student registration and login
- Personalized student dashboard
- Connect with teachers using a unique connection code
- Access learning materials, documents, and videos
- View and submit assignments
- Attempt quizzes and exams
- View quiz results and academic performance
- Maintain personal notes and study goals
- Track study progress and revision plans
- Ask learning-related questions through the AI assistant
- Discover relevant educational videos through YouTube recommendations

### 👩‍🏫 Teacher Features
- Teacher registration and login
- Personalized teacher dashboard
- Generate and share a teacher connection code
- View and manage connected students
- Upload, view, and manage learning materials
- Create and manage assignments
- Review student assignment submissions
- Create quizzes and exams
- Monitor student results and academic progress

### 🛡️ Admin and Platform Management
- Role-based access for students, teachers, and administrators
- Protected routes and authenticated API requests
- Centralized management of learning resources and platform data

### 🤖 AI-Powered Learning
- AI-assisted learning support
- Responses to educational questions
- YouTube learning recommendations
- Support for independent study and revision
